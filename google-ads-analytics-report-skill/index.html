FAQ

Your Questions Answered

Everything you need to know about this skill.

What data format does the skill accept?⌄

Any standard Google Ads export — from the Ads interface, Editor, or a spreadsheet. The skill handles the formatting.

Can it report on Search, Shopping, and Display separately?⌄

Yes. Include campaign type in your data and the skill will analyse each campaign type and objective separately.

Can I include keyword-level data?⌄

Yes — include keyword performance data and the skill will add a keyword insights section to the report.

How is this different from the Google Ads Reporting Skill?⌄

This version is designed for analytics and cross-channel reporting workflows. It emphasises multi-channel context and integrates well with GA4 and other channel data.

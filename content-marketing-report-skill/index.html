FAQ

Your Questions Answered

Everything you need to know about this skill.

What data sources does this skill work with?⌄

GA4 for website data, your CMS analytics, Google Search Console for organic search, and social platform analytics — paste the data from each source.

Can it analyse blog content separately from landing pages?⌄

Yes. Include content type or page category in your data and the skill will segment the analysis accordingly.

Does it identify SEO opportunities?⌄

Yes — include Search Console data and the skill will identify content that ranks but doesn't convert, and topics with untapped search demand.

How often should I use this?⌄

Monthly for most teams. For high-output content programmes, a bi-weekly run keeps the strategy aligned with what's performing.

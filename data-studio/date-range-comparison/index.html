Step by Step

Date Range Comparison in Data Studio

Follow these steps alongside the video to add a comparison date range to your report.

1

Select any visualisation

  • Click on a Scorecard, Time series chart, or Table in your report
  • Comparison date ranges are supported on these chart types
2

Navigate to the SET-UP column

  • Look at the right-hand panel — click the SET-UP tab if it is not already active
3

Scroll down and find the "Comparison Date Range"

  • The Comparison Date Range field appears below the main Date Range section in the SET-UP panel
4

Open the drop-down menu and customise the comparison date range

  • Click the first drop-down to choose a comparison type (e.g. Previous period, Previous year, Custom)
  • Open the second drop-down to customise the exact comparison window if needed
  • The chart will immediately show comparison delta values once a range is set

FAQ

Frequently Asked Questions

Common questions about date range comparisons in Looker Studio.

What is a comparison date range in Looker Studio? ⌄

A comparison date range lets you display a second time period alongside your primary date range on a chart or scorecard. Looker Studio calculates the difference (delta) and can show it as an absolute number or percentage change — making it easy to see whether performance improved or declined period over period.

Which chart types support comparison date ranges? ⌄

Comparison date ranges are supported on Scorecards, Time series charts, and Tables. Bar charts, pie charts, and geo maps do not currently support this feature natively — you would need to use blended data or calculated fields for those chart types.

What comparison options are available? ⌄

Looker Studio offers several built-in options: Previous period (matches the length of your primary range), Previous year (same dates one year prior), Same period last year, and Custom — where you define the exact start and end dates of the comparison window.

Does the comparison date range override the report-level date range control? ⌄

The comparison date range set in the SET-UP panel is a chart-level override. If you have a Date Range Control widget on your report, viewers can change the primary date range — the comparison will shift relative to whatever primary range is selected. If you want a fixed comparison, set a fixed date range on the chart instead of using the report control.

Can I show the comparison as a percentage change? ⌄

Yes. On a Scorecard, once the comparison date range is set, you can choose to display the delta as a percentage change or as an absolute value in the chart's STYLE tab. For time series charts, the comparison period appears as a second line — hover tooltips show both values side by side.

Why is the Comparison Date Range field greyed out? ⌄

The field is greyed out when the selected chart type does not support comparisons, or when the chart's date dimension is not set. Make sure your chart has a valid date field in the Date Range Dimension slot in SET-UP. If you are in View mode rather than Edit mode, switch to Edit mode first.

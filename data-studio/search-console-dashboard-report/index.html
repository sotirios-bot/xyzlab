Step by Step

Google Search Console Report in Data Studio

Follow these steps alongside the video to build your SEO dashboard.

1

Open Looker Studio and create a new blank report

  • Go to lookerstudio.google.com and click Blank Report
  • Give the report a name (e.g. "SEO — Search Console Dashboard")
2

Add Google Search Console as a data source

  • When prompted to add a data source, search for and select Google Search Console
  • Authorise access and choose your site property
  • Select the table type — Site Impression for overall traffic or URL Impression for page-level data
  • Click Add to connect the data source to your report
3

Add Scorecard widgets for your key SEO metrics

  • Insert Scorecards for Clicks, Impressions, CTR, and Average Position
  • Use the SET-UP panel to assign the correct metric to each Scorecard
4

Add a Time Series chart for trend visibility

  • Insert a Time Series chart and set the date dimension to Date
  • Add Clicks and Impressions as metrics to see performance over time
5

Add a Table for top queries or pages

  • Insert a Table and set the dimension to Query (for keywords) or Landing Page (for URLs)
  • Add Clicks, Impressions, CTR, and Position as columns
  • Sort by Clicks descending to surface your top performers
6

Add a Date Range Control and finalise the layout

  • Insert a Date Range Control so viewers can adjust the reporting period
  • Tidy up the layout, add a report title, and switch to View mode to review the finished dashboard

FAQ

Frequently Asked Questions

Common questions about building a Google Search Console report in Looker Studio.

Can I connect Google Search Console directly to Looker Studio? ⌄

Yes. Looker Studio has a native Google Search Console connector — no third-party tool or Google Sheets export needed. When adding a data source, search for "Google Search Console", grant access, and select your property. The connector supports both Site Impression and URL Impression table types.

What is the difference between Site Impression and URL Impression? ⌄

Site Impression aggregates data at the site level and lets you break it down by Query, Country, Device, or Search Type. URL Impression shows data at the individual page (URL) level and supports the same dimensions plus Landing Page. Use URL Impression when you need page-specific performance data.

How far back does the Search Console data go in Looker Studio? ⌄

The Google Search Console connector reflects the same data retention as Search Console itself — up to 16 months of historical data. Keep in mind that GSC data typically has a 2–3 day lag, so the most recent days may show incomplete numbers.

Can I add multiple Search Console properties to the same report? ⌄

Yes. You can add multiple data sources to a single Looker Studio report — one per property. To compare properties side by side, use Blend Data to merge them, or simply add separate charts for each data source and segment the report by property.

Why does my CTR show as a decimal instead of a percentage? ⌄

By default, CTR is stored as a decimal (e.g. 0.05 = 5%). To display it as a percentage in your charts, select the CTR metric in the SET-UP panel, click the pencil icon to edit the field, and change the Type to Percent. This formats it correctly across all charts in the report.

Can I share the Looker Studio report with a client who doesn't have GSC access? ⌄

Yes. When you share the report, you can choose to use Owner's credentials for the data source — this means viewers see the data using your GSC access, without needing their own. Go to Resource > Manage added data sources, edit the connector, and switch credentials to Owner's credentials.

Step by Step

Track Meta Ads Events with Event Setup Tool

Follow these steps alongside the video to create a no-code Meta Pixel event using the Event Setup Tool.

1

Navigate to Events Manager

  • Go to business.facebook.com/events_manager2/ and make sure you are in the correct Business Manager account
2

Navigate to Data Sources

  • In the left-hand menu, click Data Sources and select your Meta Pixel (Dataset)
3

Click the "Add Event" drop-down button

  • Look for the Add Event button at the top of the pixel overview screen and click the drop-down arrow
4

Select "Add new integration"

5

Select "Meta Pixel"

  • Choose Meta Pixel as the integration method from the options presented
6

Select "Event Setup Tool"

  • Choose the Event Setup Tool option — this is the no-code method that lets you click on elements directly in your browser
7

Open the Event Setup Tool

  • Click Open Event Setup Tool to launch the tool
8

Paste the URL where your event lives and open the tool

  • Enter the full URL of the page containing the button or element you want to track
  • The Event Setup Tool will open your website inside a special overlay window
9

Click "Track a new button"

  • In the Event Setup Tool overlay, click Track a new button to begin setting up the event
10

Select the button you want to track

  • Click on the button or element on your page that you want to associate with the event
  • The tool will highlight it and prompt you to configure the event details
11

Configure your event

  • Select the event type (e.g. Lead, Purchase, Contact) from the dropdown
  • Add any optional event parameters such as currency or value if applicable
12

Confirm and finish your setup

  • Click Confirm to save the event rule
  • Click Finish Setup to close the tool — your event is now live and will fire when the button is clicked
  • Verify the event in Events Manager → Test Events by triggering it on your website

FAQ

Frequently Asked Questions

Common questions about using the Meta Event Setup Tool to track pixel events.

What is the Meta Event Setup Tool?

The Meta Event Setup Tool is a no-code feature in Meta Events Manager that lets you create pixel event rules by clicking directly on buttons and elements on your website — without writing any JavaScript. It works by overlaying your website in a special browser window and applying CSS selector-based rules that fire events when users interact with the selected elements. It's ideal for marketers who don't have developer access to modify website code.

Do I need to have the Meta Pixel installed before using the Event Setup Tool?

Yes. The Event Setup Tool builds on top of an existing Meta Pixel installation — the base pixel code must already be installed on your website before you can use the tool to add individual event rules. If your pixel is not yet installed, install it first (via manual code, Google Tag Manager, or a platform integration) and then return to Events Manager to use the Event Setup Tool.

What types of events can I track with the Event Setup Tool?

The Event Setup Tool supports Meta's standard events including Lead, Purchase, Contact, ViewContent, AddToCart, InitiateCheckout, and more. You can assign these event types to button clicks or page loads. For more complex event logic (e.g. tracking form submissions with dynamic values), you may need to implement events via code or Google Tag Manager instead.

How do I verify that my Event Setup Tool event is firing correctly?

After setting up the event, go to Events Manager → Test Events and enter your website URL. The Test Events panel shows real-time events as they fire — click the button you set up and confirm the event appears in the panel. You can also use the Meta Pixel Helper Chrome extension to see all events firing on a page as you interact with it.

What is the difference between the Event Setup Tool and adding code manually?

The Event Setup Tool creates CSS selector-based rules that are stored in Meta and applied to your pixel automatically — no code changes needed. Manual code implementation involves adding JavaScript event handlers directly to your website's HTML or tag manager. Manual code is more reliable and flexible (it can pass dynamic parameters like order values), while the Event Setup Tool is faster to deploy but can break if your website's CSS structure changes.

Can I edit or delete events created with the Event Setup Tool?

Yes. Go to Events Manager → Data Sources → your pixel → Settings → Event Setup Tool to view all rules you've created. You can edit the event type or parameters, or delete a rule entirely. Note that deleting an Event Setup Tool rule removes the event from firing but does not affect any historical data already recorded in your pixel.

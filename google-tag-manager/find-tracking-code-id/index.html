Step by Step

Find Google Tag Manager Tracking Code and ID

Follow these steps alongside the video to locate your GTM container ID and install snippet.

1

Go to tagmanager.google.com

  • Make sure you are on the Accounts overview page
  • You can already see your Container ID (e.g. GTM-XXXXXXX) listed under the Container ID column for each account
2

Select your Google Tag Manager container

  • Click on the container name to open it
3

Navigate to Admin (top-left menu)

  • Click the Admin tab in the top navigation bar
4

View the Container ID next to your container name

  • On the right-hand side under Container, you will see the Container ID (e.g. GTM-XXXXXXX) displayed next to the container name
5

Click "Install Google Tag Manager" to get the tracking code

  • This opens the install snippet dialog with the two code blocks you need to paste into your website
  • The first snippet goes in the <head> section of every page
  • The second snippet goes immediately after the opening <body> tag

FAQ

Frequently Asked Questions

Common questions about finding and using your Google Tag Manager container ID and tracking code.

What is a Google Tag Manager container ID? ⌄

A Google Tag Manager container ID is a unique identifier assigned to each GTM container. It follows the format GTM-XXXXXXX (e.g. GTM-ABC1234). This ID is used both in the install snippet you add to your website and when referencing your container in integrations or documentation. Each website or app you manage in GTM has its own separate container with its own unique ID.

Where do I paste the GTM tracking code on my website? ⌄

GTM provides two code snippets. The first — a JavaScript snippet — should be placed as high as possible in the <head> section of every page on your website. The second — a <noscript> iframe snippet — should be placed immediately after the opening <body> tag. Both are required for GTM to work correctly, especially for users who have JavaScript disabled. Many CMS platforms (WordPress, Wix, Shopify) have dedicated fields or plugins that insert these snippets automatically.

What is the difference between the GTM container ID and the tracking code? ⌄

The container ID (e.g. GTM-XXXXXXX) is just the unique identifier for your GTM container. The tracking code (or install snippet) is the full JavaScript and noscript code blocks that you paste into your website's HTML — these blocks include the container ID embedded within them. You need the full tracking code snippet to actually install GTM; the container ID alone is used when referencing your container in other tools or integrations.

How do I know if GTM is installed correctly on my website? ⌄

The easiest way is to use GTM Preview Mode — click the Preview button in your GTM container and enter your website URL. If GTM is installed correctly, the Tag Assistant panel will open alongside your site and confirm the container is firing. You can also install the Tag Assistant Legacy Chrome extension, which checks for GTM (and other Google tags) on any page you visit and reports whether they are detected correctly.

Can I have multiple GTM containers on the same website? ⌄

Yes, technically you can install multiple GTM containers on a single website, and some organisations do this when different teams manage different sets of tags. However, it is generally not recommended as it can cause duplicate tracking, slower page loads, and difficult-to-debug tag conflicts. Best practice is to use a single container per website and manage all your tags, triggers, and variables within it.

Do I need a new GTM container for each website I manage? ⌄

Yes. Each website should have its own dedicated GTM container. Within a single GTM account you can create multiple containers — one per website or app. This keeps your tags, triggers, and variables separate and organised by property, and ensures that publishing a change to one site's container never affects another site. You can manage all containers from the same GTM account at tagmanager.google.com.

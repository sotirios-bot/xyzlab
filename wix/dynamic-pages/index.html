Create Dynamic Pages in WIX Studio

Watch the step-by-step walkthrough below, then follow along with the guide to build CMS collections and connect them to dynamic pages that auto-generate content for each item.

Step by Step

Create Dynamic Pages in WIX Studio

Follow these steps alongside the video to build your CMS collection and connect it to dynamic pages.

1

Navigate to your Wix Studio

2

Select CMS from the left-hand-side menu

  • The CMS (Content Management System) is where all your dynamic content is stored
3

Create a new Collection

  • A collection is a database of content — for example, a list of team members, blog posts, properties, or products
  • Give your collection a descriptive name
4

Add Items — each item represents a page

  • Each row in the collection becomes one dynamic page on your site
  • For example, if you add 10 team members, Wix will generate 10 individual pages automatically
5

Add Fields — each field represents an element on your dynamic page

  • Fields are the columns of your collection — e.g. Name, Photo, Description, Price
  • Each field will map to a text, image, or other element on the dynamic page template
6

Fill in your field values

  • Enter the content for each item across all fields
  • This is the data that will populate each auto-generated page
7

Create a dynamic page or convert an existing page

  • To create a new dynamic page: add a new page and select the dynamic page option
  • To convert an existing page: click the 3 dots next to the page name in the Pages panel and select Convert to Dynamic Page
  • Link the dynamic page to your CMS collection when prompted
8

Design the page template as you normally would

  • This template will be used for every item in the collection — design it once and it applies to all pages
9

Connect each element to its corresponding field

  • Select a text box, image, or other element on the page
  • Click the connection symbol (link icon) that appears in the toolbar
  • Select the CMS field that should populate that element (e.g. connect a text box to the "Name" field, an image to the "Photo" field)
  • Repeat for all elements — Wix will auto-fill each page with the correct content from your collection

FAQ

Frequently Asked Questions

Common questions about dynamic pages and the CMS in Wix Studio.

What is a dynamic page in Wix Studio? ⌄

A dynamic page is a single page template that automatically generates multiple individual pages based on items in a CMS collection. Instead of building 50 separate pages for 50 products or team members, you design the template once and Wix renders a unique page for each item in your collection. Each page gets its own URL, making it fully SEO-indexable.

What is the difference between Wix CMS and a regular Wix page? ⌄

A regular Wix page is static — you manually add and edit every piece of content directly on the page. A CMS-powered dynamic page is template-driven — the content comes from a collection (database), and the page layout stays consistent while the data changes per item. CMS pages are ideal for any repeating content type: blog posts, listings, team members, portfolios, or FAQs at scale.

Are dynamic pages in Wix Studio good for SEO? ⌄

Yes. Each dynamic page gets its own unique URL and can have its own meta title, meta description, and structured content — all pulled from CMS fields you define. You can even create a dedicated SEO field in your collection to control the meta description per item. This makes dynamic pages an efficient way to build large content libraries (e.g. local landing pages, product pages) that rank in Google without manually creating each page.

What types of fields can I add to a Wix CMS collection? ⌄

Wix CMS supports a wide range of field types including: Text, Rich Text, Number, Date & Time, Image, Video, Boolean (Yes/No), URL, Email, Address, and Reference (to link items across collections). You can mix and match field types to model almost any content structure — from simple team bios to complex product catalogues.

Can I show a list of dynamic pages on another page? ⌄

Yes — this is called a dynamic list page. In addition to the item template (which shows one item's detail), you can create a list page that displays all items in your collection as a grid or list. Each item in the list links to its individual dynamic page. This is the standard pattern for blogs (index page → article page), team directories (team page → person page), or property listings (all listings → individual listing).

Is the CMS available on all Wix plans? ⌄

The Wix CMS is available on most paid plans, but the number of items you can store and the ability to use dynamic pages with custom collections may be limited on lower-tier plans. Wix Studio (aimed at agencies and professional developers) has full CMS access. Check your current plan in Wix's billing settings if you're unsure — upgrading to a Business or Studio plan unlocks the full CMS feature set.

FAQ

Frequently Asked Questions

Common questions about restoring old site versions in WIX.

How far back can I restore my Wix site? ⌄

Wix keeps a history of your site versions whenever you publish. You can browse all previous published versions in Site History — there is no fixed limit on how far back you can go, so you have access to the full publishing history of your site.

Will restoring a previous version affect my live site immediately? ⌄

Yes. When you click Restore, Wix publishes that version directly to your live site. Visitors will see the restored version immediately after the process completes. Make sure you've selected the correct version before confirming the restore.

Can I preview a previous version before restoring it? ⌄

Yes. In Site History, each version entry has a Preview option that lets you see what that version looked like before you commit to restoring it. This is useful when you're unsure which version to roll back to and want to compare a few options first.

Will I lose my current site if I restore an older version? ⌄

Your current version is automatically saved as an entry in Site History before the restore happens. This means you can always return to your current version if the restore doesn't give you what you expected — just go back to Site History and restore the entry you want.

Does Site History save unpublished changes? ⌄

No. Site History only records published versions of your site. If you made changes in the editor but never hit Publish, those changes are not saved as a version in Site History. To avoid losing work, publish your site regularly — each publish creates a new restore point.

Can I restore a previous version if I'm using Wix Studio? ⌄

Yes. Site History is available in both WIX Studio and the classic Wix Editor. The quickest way to access it in either editor is via the search bar in the backend — simply search for "Site History" and it will appear as an option.

Add WIX Website on Bing Webmaster Tools

Watch the step-by-step walkthrough below, then follow along with the guide to verify your Wix site in Bing Webmaster Tools — either by importing from Google Search Console or using the HTML Meta Tag method.

Step by Step

Add WIX Website on Bing Webmaster Tools

Start with these three steps, then choose Option A (fastest) or Option B (manual verification).

1

Login to Bing Webmaster Tools

  • Go to bing.com/webmasters and sign in with a Microsoft account
2

Click on the drop-down menu on the top-left-hand side

3

Click on the Add a site button

A  ·  Import from Google Search Console (Fastest)
1

Select "Import from Google Search Console"

  • This option imports your verified sites, sitemaps, and some historical data from Google Search Console in one click
2

Login to your Google account and authorise the import

  • Bing will pull all properties you have access to in Google Search Console
  • Select the Wix site you want to import and confirm — verification is instant
▶   Or verify manually:
B  ·  Add Your Site Manually (HTML Meta Tag)
1

Enter your site URL

  • Type your full Wix homepage URL (e.g. https://www.yoursite.com/) and click Add
2

Click on HTML Meta Tag

  • Select the HTML Meta Tag verification option from the list
3

Copy the code

  • Copy the full <meta> tag shown — keep this tab open, you'll need it shortly
4

Navigate to your Wix backend

  • Log in to manage.wix.com and select your site
5

Navigate to Site Verification

  • Go to Settings → Marketing Integrations → Site Verification
6

Select Bing Webmaster

7

Paste the code and save

  • Paste the <meta> tag you copied from Bing Webmaster Tools and save your changes
8

Return to Bing Webmaster Tools and click Verify

  • Go back to the Bing Webmaster Tools tab and click Verify
  • Once verified, Bing will start crawling and indexing your Wix site

FAQ

Frequently Asked Questions

Common questions about adding a Wix website to Bing Webmaster Tools.

Why should I add my Wix site to Bing Webmaster Tools? ⌄

Bing is the second largest search engine globally and powers search on Microsoft Edge, Yahoo, and Copilot. Adding your site to Bing Webmaster Tools lets you monitor how Bing crawls and indexes your Wix pages, see which search queries bring traffic from Bing, identify crawl errors, and submit your sitemap to speed up indexing. It's a free 10-minute setup that can meaningfully expand your organic search reach.

Which verification method is faster — importing from Google Search Console or the HTML Meta Tag? ⌄

Importing from Google Search Console is by far the fastest option — it takes about 30 seconds and also imports your sitemaps and some historical data automatically. Use the HTML Meta Tag method if you don't have Google Search Console set up yet or prefer to verify each tool independently. Both methods result in the same level of access in Bing Webmaster Tools.

Do I need a Microsoft account to use Bing Webmaster Tools? ⌄

Yes. You need to sign in with a Microsoft account (Outlook, Hotmail, or any Microsoft 365 email) to access Bing Webmaster Tools. If you don't have one, you can create a free account at microsoft.com. Alternatively, Bing Webmaster Tools also allows sign-in via Google or Facebook accounts, so you may not need a dedicated Microsoft account.

How long does it take for Bing to start indexing my Wix site after verification? ⌄

Verification is instant, but Bing typically takes a few days to a few weeks to crawl and index your Wix pages after verification. Submitting your sitemap (go to Sitemaps → Submit a Sitemap and enter yoursite.com/sitemap.xml) can significantly speed up the process. If you imported from Google Search Console, your sitemap is usually imported automatically.

Should I submit a sitemap to Bing after verification? ⌄

Yes — submitting a sitemap is highly recommended. Wix automatically generates a sitemap at yoursite.com/sitemap.xml. In Bing Webmaster Tools, go to Sitemaps in the left menu and submit that URL. This tells Bing exactly which pages exist on your site and helps it discover new content faster, especially for pages that don't have many external links pointing to them.

What can I do in Bing Webmaster Tools once my Wix site is verified? ⌄

Once verified, you can: view search performance data (impressions, clicks, average position on Bing), inspect individual URL indexing status, submit URLs for on-demand crawling, check for crawl errors, use the SEO analyser to find on-page issues, and monitor your backlink profile. Bing Webmaster Tools also offers an AI-powered SEO recommendations feature that suggests specific improvements for your pages.

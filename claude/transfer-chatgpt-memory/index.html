Step by Step

Transfer ChatGPT Memory to Claude

Follow these steps alongside the video to move your ChatGPT memories into Claude.

1

Login to Claude

2

Navigate to Settings

3

Select Capabilities

4

Toggle on all options under Memory

  • Make sure all available Memory toggles are enabled before proceeding to the import step
5

Click on Start Import

6

Copy the Prompt

  • Claude generates a ready-made prompt designed to extract your memory data from ChatGPT in the correct format
7

Navigate to ChatGPT and paste the prompt

  • Open ChatGPT in a new tab and paste the copied prompt into a new conversation
  • ChatGPT will return a structured summary of all your saved memories
8

Copy the output

  • Select and copy the full response that ChatGPT generates
9

Paste the output in Claude

  • Return to the Claude import flow and paste the ChatGPT output into the provided field
10

Import memory

  • Confirm the import and Claude will save all transferred memories to your profile
  • Your preferences, context, and stored facts from ChatGPT will now be available in future Claude conversations

FAQ

Frequently Asked Questions

Common questions about transferring ChatGPT memory to Claude.

Can I really transfer my ChatGPT memory to Claude?

Yes. Claude has a built-in memory import feature under Settings → Capabilities. It generates a prompt you run in ChatGPT, which returns a structured export of your stored memories. You then paste that output back into Claude to complete the transfer — no third-party tools required.

Will all my ChatGPT memories transfer perfectly to Claude?

The import transfers the content of your saved memories — your preferences, context, and stored facts. The formatting may differ slightly since Claude and ChatGPT store memories differently, but all meaningful information should carry over. Review your Claude memories after the import to confirm everything looks correct.

Do I need a paid Claude plan to use memory import?

The Memory feature in Claude is generally available to Claude Pro and Team plan subscribers. Free plan users may have limited or no access to memory features. Check Claude's current plan comparison page for the most up-to-date availability details.

What happens to my existing Claude memories when I import from ChatGPT?

Importing from ChatGPT adds to your existing Claude memories rather than replacing them. If there are any conflicts or duplicates, Claude will merge the information intelligently. You can review and manage all memories in Settings → Capabilities after the import is complete.

Can I also transfer my Gemini memory to Claude?

Yes. Claude supports memory imports from both ChatGPT and Gemini. The process is identical — enable Memory in Capabilities, click Start Import, copy the generated prompt, run it in Gemini, then paste the output back into Claude. See our Transfer Gemini Memory to Claude tutorial for the full walkthrough.

Is my ChatGPT memory data safe when I use this import method?

The transfer happens entirely within your own browser sessions — you copy text from ChatGPT and paste it into Claude. No data is sent to any third-party service or tool. Both Anthropic (Claude) and OpenAI (ChatGPT) handle your data according to their own privacy policies, which govern how each platform stores and processes your memories.

Create WordPress Pages with Claude Code

Follow these steps alongside the video to build your WordPress page using Claude Code.

1

Use the Code Editor in WordPress

  • Open your WordPress dashboard and navigate to the page you want to edit
  • Click the three-dot menu (⋮) in the top-right corner of the block editor and select Code editor
  • This switches the editor to raw HTML/block markup mode where you can paste code directly
2

Create the code in Claude Code and paste it in WordPress

  • Open Claude Code and describe the page you want to build — include layout, sections, and any specific content
  • Claude Code will generate the HTML or WordPress block markup for your page
  • Copy the generated code and paste it into the WordPress Code Editor
  • Click Exit Code Editor to return to the visual editor and preview your page
  • Click Update or Publish to make the changes live

FAQ

Frequently Asked Questions

Common questions about creating WordPress pages with Claude Code.

What is Claude Code? ⌄

Claude Code is Anthropic's AI-powered coding assistant that runs in your terminal or IDE. It can read, write, and edit code files, run commands, and build entire projects from natural language instructions. For WordPress, you can use it to generate HTML, CSS, PHP, or WordPress block markup that you then paste directly into your site.

What is the WordPress Code Editor? ⌄

The Code Editor is a built-in view inside the WordPress block editor (Gutenberg) that lets you see and edit the raw block markup of a page. You access it via the three-dot menu in the top-right corner of the editor. It is different from the Theme File Editor — it is specifically for editing the content of a single page or post.

Do I need coding experience to use Claude Code for WordPress? ⌄

No. You describe what you want in plain English and Claude Code generates the code for you. Basic familiarity with copying and pasting into WordPress is all you need. The more specific your description — layout, colours, sections, content — the more accurate the output will be.

What types of pages can I create with Claude Code in WordPress? ⌄

You can create any page type: landing pages, service pages, about pages, contact pages, pricing pages, and more. Claude Code can generate WordPress block markup (compatible with Gutenberg), plain HTML wrapped in a Custom HTML block, or PHP templates if you are comfortable adding them to your theme files.

Is Claude Code free to use? ⌄

Claude Code requires an Anthropic API key and usage is billed based on the number of tokens processed. There is no free tier for Claude Code specifically, but costs are typically very low for building individual pages. You can set a spending limit in your Anthropic account to control usage.

Can I use Claude Code to edit existing WordPress pages? ⌄

Yes. Copy the existing code from the WordPress Code Editor, paste it into Claude Code with instructions for what to change, and Claude will return the updated version. This works well for redesigning sections, adding new content blocks, or fixing layout issues without starting from scratch.

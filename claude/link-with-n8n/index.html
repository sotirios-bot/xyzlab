Step by Step

Link n8n with Claude

Follow these steps alongside the video to connect n8n to your Claude account.

1

Navigate to Settings

  • Click your profile icon or name in Claude to open the Settings menu
2

Select Connectors

  • The Connectors tab lists all third-party integrations available to link with Claude
3

Find n8n, select Configure, login and authorise

  • Locate n8n in the connectors list and click Configure
  • Enter your n8n instance URL when prompted (your self-hosted or n8n Cloud URL)
  • Log in to your n8n account if prompted, then approve the connection to grant Claude access
  • Once authorised, Claude can list, trigger, and interact with your n8n workflows directly from conversations

FAQ

Frequently Asked Questions

Common questions about linking n8n with Claude.

What can Claude do once n8n is connected?

Once n8n is linked, Claude can list your workflows, trigger executions, and check run status conversationally. Instead of opening the n8n UI to kick off an automation, you can simply tell Claude to run a specific workflow — making it easy to initiate complex multi-step automations across any of the 400+ apps n8n supports.

Does this work with self-hosted n8n as well as n8n Cloud?

Yes. The connector works with both n8n Cloud and self-hosted n8n instances. For self-hosted setups, your n8n instance must be publicly accessible (or accessible via a tunnel) so Claude can reach it during the authorisation flow and when triggering workflows.

Do I need a paid Claude plan to use Connectors?

Connectors (including the n8n integration) are available on Claude Pro and Team plans. Free plan users generally cannot access third-party connectors. Check Claude's current plan comparison page for the latest feature availability.

How is linking n8n to Claude different from building an n8n workflow that uses Claude?

These are two different directions of integration. Linking n8n to Claude (this tutorial) lets Claude trigger your n8n workflows from a conversation. Building an n8n workflow that uses Claude means n8n calls the Claude API as a step inside an automation — for example, to summarise data or generate content as part of a larger pipeline. Both approaches can be combined for powerful AI-driven automation.

How do I disconnect n8n from Claude?

To disconnect, go to Settings → Connectors in Claude and remove the n8n connection. You can also revoke the API credential from within n8n by going to Settings → API and deleting the key that was generated for Claude. Either action immediately cuts off Claude's access to your n8n instance.

Is my n8n workflow data safe when connected to Claude?

Anthropic accesses your n8n data only to respond to your requests in Claude — your workflow configurations and execution data are not used to train AI models. For self-hosted instances, make sure your n8n server is secured with HTTPS and proper authentication before exposing it for the Claude connection.
